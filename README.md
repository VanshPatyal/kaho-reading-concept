# Kaho Reading Concept

An independent reading and learning interface concept featuring focused reading, highlights, notes, and illustrative AI assistance. This is a personal portfolio concept and is not an official Kaho product.

## Live demo

https://vanshpatyal.github.io/kaho-reading-concept/kaho-concept.html

## Screens

- Focused reading
- Contextual Ask AI panel with illustrative, non-connected responses
- Notes and highlights with navigation back to source passages

## Run locally

Open `kaho-concept.html` in a browser. The prototype is built with HTML, CSS, and JavaScript and does not require a build step.

## Publishing

The GitHub Actions workflow in `.github/workflows/publish-kaho-pages.yml` publishes the standalone prototype to GitHub Pages when run manually from the Actions tab.
